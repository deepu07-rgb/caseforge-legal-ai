# G-DOCS-REAL

Rights-tracked real-world document fixtures for Stage 3. Run
`python eval/tools/fetch_stage3_public_fixtures.py` to acquire the official
source and reproducibly build format/scan derivatives. Downloaded assets are
internal-evaluation inputs and are not approved for client redistribution.

`READY_FOR_REVIEW` is not `GOLDEN`. A human must review the expected answer and
lock the fixture before its results can count as PASS evidence.
